Project 6: Google Search Trends Analysis

Dataset: Google Trends (via pytrends API)
Introduction:
Search trends reflect public interest in topics like cryptocurrency, AI, and elections. This project
analyzes keyword trends over time and across regions.

Key Questions to Answer:
1. How do search trends for "Bitcoin" vary by country?
2. Are there seasonal patterns in searches for "Artificial Intelligence"?
3. Can search trends predict real-world events (e.g., elections)?
   
Tasks to Perform:
● Fetch data using pytrends.
● Plot time-series trends.
● Perform correlation analysis with external datasets.

Deliverables:
● Trend analysis report.
● Geo-visualizations (Plotly/Folium).
